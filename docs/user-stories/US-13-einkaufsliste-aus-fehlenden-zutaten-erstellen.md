# US-13 – Einkaufsliste aus fehlenden Zutaten erstellen

Als Nutzer möchte ich die fehlenden Zutaten eines Rezepts auf eine Einkaufsliste setzen, damit ich gezielt einkaufen kann.

## Akzeptanzkriterien

- Für ein ausgewähltes Rezept werden die benötigten Zutaten mit dem aktuellen Vorrat verglichen.
- Zutaten, die bereits in ausreichender Menge vorhanden sind, werden nicht zur Einkaufsliste hinzugefügt.
- Bei teilweise vorhandenem Vorrat wird nur die fehlende Menge übernommen.
- Gleiche Zutaten mit derselben Einheit werden auf der Einkaufsliste zusammengefasst.
- Ein Eintrag kann als erledigt markiert und wieder geöffnet oder von der Liste entfernt werden.
- Ist keine Zutat nötig, erscheint ein verständlicher Hinweis.
