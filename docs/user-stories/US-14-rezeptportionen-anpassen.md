# US-14 – Rezeptportionen anpassen

Als Nutzer möchte ich die Portionszahl eines Rezepts anpassen können, damit ich die benötigten Zutatenmengen für meine Gästezahl sehe.

## Akzeptanzkriterien

- Ein Rezept hat eine gespeicherte Ausgangs-Portionszahl.
- Auf der Rezeptdetailseite kann ich eine gewünschte positive ganze Portionszahl eingeben.
- Die angezeigten Zutatenmengen werden proportional zur Ausgangs-Portionszahl berechnet.
- Die gespeicherten Originalmengen des Rezepts bleiben unverändert.
- Bei einer ungültigen Portionszahl wird eine verständliche Rückmeldung angezeigt.
