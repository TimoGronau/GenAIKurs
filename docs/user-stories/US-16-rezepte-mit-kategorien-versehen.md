# US-16 – Rezepte mit Kategorien versehen

Als Nutzer möchte ich Rezepte Kategorien oder Schlagwörter zuordnen und danach filtern können, damit ich passende Gerichte schneller finde.

## Akzeptanzkriterien

- Beim Anlegen und Bearbeiten eines Rezepts können eine oder mehrere Kategorien oder Schlagwörter gepflegt werden.
- Kategorien können zum Beispiel „Frühstück“, „Vegetarisch“ oder „Schnell“ heißen.
- Die Rezeptübersicht kann nach einer oder mehreren ausgewählten Kategorien gefiltert werden.
- Ein Rezept ohne Kategorie bleibt weiterhin in der Übersicht auffindbar.
- Wird kein Rezept für die gewählten Kategorien gefunden, erscheint ein entsprechender Hinweis.
